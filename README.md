# cafe-website-practice
GitHub共同作業の学習用リポジトリ（架空のカフェWebサイト素材）

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `index.html` | カフェのトップページ（ブラウザで表示可能） |
| `concept.md` | カフェのコンセプト素材 |
| `menu.md` | メニュー素材 |
| `access.md` | アクセス情報素材 |

## サイトの表示方法

クローン後、`index.html` をブラウザで開くとカフェのWebサイトが表示されます。

```bash
git clone https://github.com/dsato0918-lab0918/cafe-website-practice.git
cd cafe-website-practice
open index.html   # Mac の場合
# start index.html  # Windows の場合
```

## 素材の編集について

`concept.md` / `menu.md` / `access.md` の各ファイルに `TODO` コメントが記載されています。
担当者はそれぞれのファイルを編集し、Pull Request を作成してください。
